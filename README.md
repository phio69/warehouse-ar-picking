# AR-система комплектации заказов для складского комплекса

Квалификационная работа: «Внедрение систем дополненной реальности в складской комплекс».

## Описание
Мобильное AR-приложение для сотрудника склада (комплектовщика). Приложение получает
задание на сборку заказа, распознаёт маркер на ячейке стеллажа и подсвечивает
в дополненной реальности нужную ячейку и количество товара.
Факт отбора передаётся на сервер и фиксируется в базе данных склада.

## Архитектура
iPhone (Unreal Engine + ARKit) - HTTP/JSON - серверный API - PostgreSQL
